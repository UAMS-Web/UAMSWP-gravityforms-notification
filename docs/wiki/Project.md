Where the plugin is developed, how it is tested, and how to report a problem.

- **Source:** [UAMS-Web/UAMSWP-gravityforms-notification](https://github.com/UAMS-Web/UAMSWP-gravityforms-notification), default branch `master`.
- **Changes:** every change starts as an issue and lands through a pull request to `master`; [CONTRIBUTING.md](https://github.com/UAMS-Web/UAMSWP-gravityforms-notification/blob/master/CONTRIBUTING.md) has the path.
- **Tests and checks:** the [README](https://github.com/UAMS-Web/UAMSWP-gravityforms-notification#tests) explains the Unit suite, the WordPress Integration suite and its disposable test database, and the checks every pull request runs.
- [Report a problem](https://github.com/UAMS-Web/UAMSWP-gravityforms-notification/issues)
- [Releases](https://github.com/UAMS-Web/UAMSWP-gravityforms-notification/releases)

These pages are kept in [`docs/wiki/`](https://github.com/UAMS-Web/UAMSWP-gravityforms-notification/tree/master/docs/wiki) and published to this wiki by the `Publish wiki` workflow when a release is published, or by hand. Edits made in the wiki itself are overwritten by the next publish.
